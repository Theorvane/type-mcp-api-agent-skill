# Planning

Implementation plans are canonical, issue-scoped documents. Store them as `YYYY-MM-DD-issue-<number>-<topic>.md`.

Every plan must link its issue, list exact files/commands, define acceptance/error/exclusion cases, describe a focused TDD cycle for each behavior, and identify documentation changes. No generator implementation starts without a plan derived from the approved design in `docs/superpowers/specs/2026-07-21-type-mcp-api-agent-design.md`.
